How to create a Beanie migration?

```
beanie new-migration -n $(MIGRATION_NAME) -p beanie/migrations
```

Se a aplicação for executada com Ngrok, é preciso acionar o ngrok na maquina local e utilizar o endpoint gerado com "https" na variável de ambiente APP_API_BASE_PATH.

Quando fizer o upload da aplicação no Render, é preciso utilizar a URL gerada pelo Render na mesma variável de ambiente.
